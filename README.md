# scoop-outpost

Scoop bucket for **Deep Fathom Outpost** — a multi-cloud compliance posture
scanner (CLI and desktop app).

## Status: not currently published

The bucket manifests have been withdrawn. There is no supported
`scoop install` path for Outpost right now.

Existing installations are unaffected. Release artifacts remain available at
`https://cdn.deepfathom.ai/outpost/public/stable/`.

This repository is retained deliberately so the bucket name survives until
publishing resumes.
